# 阿里云香港部署资产迁移交付

本轮只把仓库中的部署资产从 DigitalOcean 模型迁移到阿里云香港轻量服务器，
不连接服务器、不修改 DNS 或云资源。历史开发日志保留当时的 DigitalOcean
事实，不回写或伪造。

## 四个阶段

1. **仓库资产迁移**：在功能分支完成脚本、模板、CI、文档与自动测试；只做
   本地提交，复审前不推送、不合并。
2. **服务器实际部署**：经单独授权后安装运行环境、创建目录和服务、上传并
   校验发布包。不得撤销现有 SSH、UFW、cloud-init hold 或 FIFO 0600 缓解。
3. **站外备份**：当前没有 OSS 授权。真实联系人数据或课件进入系统前，必须
   单独批准远程加密仓库，并完成备份与隔离恢复演练。同盘副本不算站外备份。
4. **DNS 与 HTTPS**：开放轻量防火墙/UFW 80/443、修改 Namecheap DNS、
   签发证书和建立监控均需执行时授权。

## 仓库实现契约

- 前端只在可信 Linux/WSL 或 CI 构建；2 GiB 服务器不执行 Node 构建。
- Linux x86_64、CPython 3.12 构建环境预下载哈希锁定的 wheelhouse，拒绝
  源码包。服务器只以 `--no-index --find-links --require-hashes` 安装。
- `package-release.sh` 生成单一归档及归档外 SHA-256；二者通过 SCP 上传。
- `verify-release-package.sh` 在独立目录校验摘要、Git SHA、路径、文件类型、
  wheel 和禁止内容，并生成确定性目录完整性清单。验证目录由 root 拥有，
  组和其他用户不可写。
- 发布包验证使用写死在验证器中的安全预算，不从待验证归档读取或接受覆盖：
  归档最大 64 MiB、最多 4096 个成员、单成员声明最大 32 MiB、总声明解压
  最大 256 MiB、压缩比最多 40:1、实际写入最大 256 MiB。2026-08-02 对当前
  正常发布内容（前端静态产物、后端源码和 Linux x86_64 wheelhouse）的实测为：
  4,060,399 字节归档、164 个成员、最大成员 2,094,516 字节、总声明解压
  5,076,126 字节、压缩比 1.25:1。这些固定上限为当前包保留明确余量，同时
  把异常归档限制在 2 GiB 目标机可控范围内。
  验证先扫描 tar 元数据和压缩比，再创建临时输出；实际解包采用受限流式复制
  复核真实写入字节，任何失败均删除临时目录、输出和临时清单，可安全重试。
- 路径先做 Unicode NFC 与 casefold 冲突检查；反斜杠、重复成员、文件/目录
  前缀冲突、任意目录的 `.env*`、嵌套/重复 wheelhouse 均被拒绝。构建 manifest
  只允许预定义唯一字段，并实际核对 Git SHA、两个 lock 摘要及 wheel 清单摘要。
- `deploy-release.sh` 在同一把 `flock` 锁中于复制前和复制后复算清单，拒绝
  验证后新增、删除或修改文件。
- `/etc/gongxing/gongxing.env` 必须先创建为 `root:gongxing 0640` 或更严格。
  临时 release 离线装好依赖后，部署脚本在切换 `current` 前执行 production
  配置检查；任何失败都清理临时目录，不影响旧服务和旧链接。
- 首次部署与后续部署都执行配置检查。检查覆盖 production、唯一可信 Origin、
  空 CORS、回环代理、持久数据路径、管理员密码以及环境文件属主/权限，并且
  不输出密码或 Key。
- 首次空状态部署使用 `--initial-deploy`；后续部署仍需已验证备份 ID。发布、
  备份、恢复共用锁及既有维护/回滚状态机。
- `OFFSITE_BACKUP_APPROVED` 只接受精确值 `1`。备份/恢复拒绝相对或本地路径、
  `file:`、localhost 和回环地址；该门禁不影响构建、普通发布和健康检查。

## 容量与运行建议

服务器有 2 GiB 内存。推荐在运行环境阶段经授权创建 1 GiB swap（最多评估到
2 GiB），只作为内存尖峰保护，不替代容量监控。前端产物和 wheelhouse均在
可信构建机产生；服务器只解包、校验和离线创建 Python venv。

## 云端边界

轻量防火墙替代 DigitalOcean Firewall，基础 CloudMonitor 替代 Monitoring。
只使用确认免费的既有 CloudMonitor 能力，不升级或修改当前有警告的厂商
cloudmonitor 服务。家庭公网 IP 变化时，先在控制台增加新 `/32`、验证新 SSH，
再删除旧规则；失联时用控制台远程连接恢复。所有真实公网、私网和家庭 IP 均
只使用运行时占位符，永不提交。

服务器到期时间为 2026-09-01 23:59:59，自动续费应保持关闭，并在到期前设置
人工提醒。当前无 OSS、快照或数据盘；增加任何资源需要重新批准。

## 仓库验收与目标机验收边界

仓库阶段运行 shell 语法、五组行为 harness、部署资产测试、后端完整测试、
前端 build/lint、CI YAML、`git diff --check` 和敏感信息扫描。`nginx -t`、
systemd 启停、真实 TLS/DNS、Basic Auth、备份恢复与线上冒烟测试只能在后续
目标机阶段验收，静态测试不能替代它们。
